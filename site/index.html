02 / CAPABILITIES
Built for expressive queries.
Engineered for control.

      

        
⌘
Composable expression trees
Combine AND, OR, NOT and collection predicates into a recursive, versioned JSON definition.
AST v1

        
▤
Metadata-first design
Entity fields, relationships and allowed operators are described by the backend—not embedded in the editor.
CATALOG

        
⟡
Safe SQL compilation
Allowlisted identifiers, typed parameter binding and bounded read-only queries for SQL Server.
SQL SERVER

        
✓
Validation with context
Semantic validation returns structured diagnostics with paths and stable node IDs for editor feedback.
DIAGNOSTICS

        
∑
Collection semantics
Express ANY, ALL and NONE across relationships with tested SQL null and empty-collection behavior.
QUANTIFIERS

        
◈
Reusable runtime inputs

05 / GET STARTED
Clone. Run. Compose.
Run the actual editor and .NET API locally. Validation and SQL compilation work without a database; row preview requires SQL Server.
Setup instructions ↗
terminal
# Requires .NET 10 SDK
$ git clone https://github.com/MatrTech/ExpressionForge.git
$ cd ExpressionForge
$ dotnet restore ExpressionForge.slnx
$ dotnet run --project src/ExpressionForge.Api --urls http://localhost:5054
