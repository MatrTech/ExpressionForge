03 · AUTHORIZATION-AWARE METADATA

          
One domain. Different permitted expressions.

          
Roles come from verified JWT claims, while grants come from trusted server configuration. Both metadata discovery and SQL compilation enforce the same field and relationship visibility.

          

            

              project-reader
              Read basic project information
              Visible: Project.Id, Name, Archived
              Unavailable: Budget, Tasks traversal
              Only granted columns appear in the generated SELECT.
            

            

              planner
              Analyze projects with tasks
              Visible: Project.Budget, Tasks.ANY
              Nested Task scope: Hours, State
              The same nested AST can be validated with role-aware scopes.

04 · MULTIPLE TRUSTED SOURCES

          
Choose a domain, keep the same expression language.

          
One ASP.NET Core API can register several independently mapped metadata catalogs. The visual editor switches schemas while retaining each catalog's draft expression and bound parameter values.

          

            

              catalog: customers · demo provider
              Customer & Orders
              Customer.FirstName, Age, IsActive
              Orders.ANY / ALL / NONE
              Existing AST v1 payloads without catalogId continue using the configured default.
            

            

              catalog: projects · JSON provider
              Projects & Tasks
              Project.Budget, Archived
              Tasks.State, Hours
              New queries can pin catalogId and catalogRevision to a trusted domain definition.
            

          

          Explore both registered sources ↗
          Read the catalog switching guide ↗
          
This GitHub Pages showcase is static. Catalog switching and compilation are available in the running .NET editor; authorization remains enforced by the API.

        

        
New: GET /api/query/metadata provides an opaque schema fingerprint, and POST /api/query/metadata/scopes discovers valid fields and types for every nested AST node. Read the API design ↗

        
Catalog mappings are trusted server configuration, not browser input. This website illustrates the validated fixtures; database execution is available only in the hosted .NET API with SQL Server configured.

07 / GET STARTED
Clone. Run. Compose.
Run the actual editor and .NET API locally. Validation and SQL compilation work without a database; row preview requires SQL Server.
Setup instructions ↗
terminal
# Requires .NET 10 SDK
$ git clone https://github.com/MatrTech/ExpressionForge.git
$ cd ExpressionForge
$ dotnet restore ExpressionForge.slnx
$ dotnet run --project src/ExpressionForge.Api --urls http://localhost:5054
